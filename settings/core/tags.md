# Tag Registry

**Single authority for tags, per `AKIRA-V3.md` §4.** Machine-readable format:
`## parent` headings, then `- child: definition` lines — scripts parse this
directly.

Rules (see `AKIRA-V3.md` §4 for the full policy):

1. A tag not in this registry is a violation - no undeclared tags, ever.
2. Max 10 tags per page.
3. A tag must be used on at least 3 pages to remain in the registry - a
   proposed tag with fewer than 3 real uses gets folded into a broader
   existing tag or dropped, not kept as a one-off.
4. Use the most specific tag; never parent + child together.
5. Tags describe *category*, not content restated (a page about a corrido
   is tagged `corrido`, not re-summarized in tags).
6. A brand-new tag (not in this list) may only be added if it will apply to
   at least 3 existing pages - propose it, add it here with a definition
   first, *then* tag the pages, same session (registry-first ordering).

TEMPLATE NOTE: the groups below are a worked example — replace them with
your own registry as your corpus takes shape. Grow it bottom-up from what
your sources actually need (rule 3), don't design it in advance.

## example-theory

- posthumanism: Work engaging post-/trans-human frameworks and critiques of humanism
- ethics: Normative frameworks, moral philosophy, applied ethics
- political-philosophy: Theories of power, the state, collective decision-making

## example-methodology

- research-methods: How inquiry itself is designed, conducted, or critiqued
- project-management: Frameworks for organizing work (agile, CPM, lean, etc.)

## example-engineering

- mechanisms: Linkages, actuators, kinematics, machine elements
- control-systems: Feedback, sensing, regulation of dynamic systems
